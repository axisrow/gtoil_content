Канистра моторного масла — это шпаргалка, но только если знать язык. Все ключевые сведения о продукте напечатаны на задней этикетке, и читать их нужно в определённом порядке: от самого строгого требования к самому общему.

<!-- more -->

## Шаг первый: допуски автопроизводителя

Самый сильный код на канистре — допуск конкретного автоконцерна: VW 504.00/507.00, MB 229.51, BMW LL-04 и тому подобные. Он означает, что масло прошло испытания по методике самого производителя для конкретных поколений моторов — с их длинными интервалами, сажевыми фильтрами и точными требованиями к зольности. Если в руководстве к вашей машине указан такой допуск, он перекрывает всё остальное: ищите его номер на этикетке дословно. «Аналогичное по свойствам» на чужой канистре — не допуск.

## Шаг второй: классы ACEA

Европейская классификация ACEA описывает тип мотора и экономичность: A/B-серии — бензин и дизель легковушек, C-серии — низкозольные масла под сажевые фильтры (C2, C3 различаются содержанием сульфатной золы и HTHS), E-серии — тяжёлый коммерческий дизель. Индекс говорит, под какие системы выпуска и режимы продукт рассчитан. Для машины с сажевым фильтром класс C — не рекомендация, а условие выживания фильтра.

## Шаг третий: API и ILSAC

Американский «круг» API маркирует уровень эксплуатационных свойств: вторая буква — поколение (для бензиновых моторов актуальна SP, для дизельных — CK-4). ILSAC GF-6A/GF-6B добавляет требования по экономичности и защите — это маркировка прежде всего японских и американских автомобилей. API — самый общий уровень: если масло имеет только его, это признак базового продукта без претензий на конкретные европейские моторы.

## Шаг четвёртый: класс вязкости SAE

Запись вида 5W-30 читается в два движения: число перед «W» — зимние свойства (провернутое и прокачанное на морозе, чем меньше — тем холоднее класс), число после — рабочая вязкость при 100 °C. Оба числа обязательны, и менять их произвольно нельзя: мотор проектируют под конкретный диапазон. Вязкость — единственный параметр, который «чувствуется» водителю (пуск на морозе, расход), но не единственный, который важен.

## Что ещё стоит на канистре

- **«Synthetic»/«синтетика»** — про маркетинг базы, а не про гарантию допуска; группу базовых масел производитель указывать не обязан.
- **Дата производства** — партия и месяц выпуска: масло не портится молниеносно, но свежесть партии означает полный запас присадок.
- **Energy conserving / Fuel economy** — отметка об экономичности; полезна, если ваш мануал допускает такие классы.
- **Базовые цифры продукта** — плотность, индекс вязкости, температура вспышки: для сравнения продуктов одной линейки, для выбора по мануалу они вторичны.

## Ловушки, на которые ловятся чаще всего

- **«Подходит для всех автомобилей»** — юридически пустая фраза: универсальной канистры не существует, допуск всегда адресный.
- **Устаревшие классы.** API SN и ILSAC GF-5 — предыдущее поколение; новые моторы их не признают, а старые — вполне себе, но лучше брать актуальное поколение: оно обратно совместимо по заявлениям API.
- **«Рекомендовано» вместо «одобрено».** Слово «рекомендовано» ничего не значит — допуск пишется кодом с номером и подтверждается листом одобрений на сайте концерна. Есть код — есть испытания; нет кода — есть только реклама.
- **Поддельная этикетка.** Кривая полиграфия, нет партии и даты, «запрещённые» сочетания классов — повод вернуть канистру на кассу. Проверка оригинальности по коду на крышке у крупных брендов — норма, а не паранойя.

## Где брать список требований

Руководство по эксплуатации — первоисточник: там указаны и вязкость, и допуски, и допустимые классы ACEA/API. Если книга утеряна, требования повторяются на сайте автопроизводителя в разделе технической документации — но не в прайс-листах продавцов масла: у дистрибьюторов своя мотивация. Онлайн-программы подбора по VIN удобны для сверки, финальное слово всегда за мануалом.

## Порядок чтения — коротко

Допуск из руководства → класс ACEA → API/ILSAC → вязкость SAE → только потом бренд и цена. Бренд не входит в этот список не потому, что неважен, а потому, что он не может ничего компенсировать: канистра без нужного допуска не станет правильной от известности имени. Если на этикетке не нашлось допуска из вашего мануала — это ответ, и искать следует дальше, а не «проверять на своей машине».
