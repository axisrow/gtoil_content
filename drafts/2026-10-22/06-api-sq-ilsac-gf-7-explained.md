С весны 2025 года в США действует новый стандарт масел для бензиновых двигателей — API SQ и ILSAC GF-7. Теперь эти обозначения массово появляются и на канистрах в России. Разбираемся, что в нём нового и стоит ли менять привычное масло.

<!-- more -->

## Кто такие API и ILSAC

- **API** (Американский институт нефти) ведёт классификацию моторных масел. Для бензиновых двигателей категории обозначаются буквой S и второй буквой по алфавиту: …SN, SP, теперь SQ. Чем дальше буква, тем новее стандарт.
- **ILSAC** — комитет американских и японских автопроизводителей. Его стандарты (GF-5, GF-6, теперь GF-7) строятся на категории API и добавляют требования к топливной экономичности. Масла ILSAC обозначаются значком-«звёздочкой» (Starburst) на канистре.

Первая дата лицензирования API SQ, ILSAC GF-7A и GF-7B — **31 марта 2025 года**. Предыдущее поколение (API SP и GF-6) действовало с мая 2020 года.

## Что изменилось по сравнению с SP и GF-6

Переход GF-6 → GF-7 эволюционный. Предыдущий шаг был крупнее: в GF-6 добавили сразу несколько новых моторных испытаний, в том числе тест на износ цепи ГРМ. GF-7 в основном **ужесточает пределы** в уже существующих испытаниях и вводит два новых теста.

По данным разработчиков стандарта и производителей присадок, GF-7 улучшает:

- защиту от **LSPI** — преждевременного воспламенения на низких оборотах в турбомоторах с непосредственным впрыском, причём как на свежем, так и на состаренном масле;
- защиту **цепи ГРМ** от износа и растяжения;
- контроль **отложений** на поршнях и в турбокомпрессоре;
- борьбу с **шламом и лаками**;
- **топливную экономичность** и защиту систем нейтрализации выхлопа;
- **прокачиваемость** на холоде;
- работу на топливе с содержанием этанола до E85.

Проще говоря, SQ/GF-7 рассчитан на современные малолитражные турбомоторы с непосредственным впрыском, которые работают на высоких нагрузках и малых оборотах, — именно они самые требовательные к маслу.

## GF-7A и GF-7B: в чём разница

ILSAC, как и раньше, разделён на две части по вязкости:

| Стандарт | Вязкости |
|---|---|
| GF-7A | 0W-20, 5W-20, 0W-30, 5W-30, 10W-30 |
| GF-7B | 0W-16 |

GF-7B выделен отдельно, потому что совместимость сверхмаловязких масел со старыми двигателями не гарантируется: 0W-16 можно лить только туда, где его разрешает производитель. Маркировку GF-7B несут масла со значком-«щитом», а не «звёздочкой». <!-- CHECK: GF-7B — значок Shield, как у GF-6B -->

Отдельно существует **API SQ-RC** (Resource Conserving): обозначение топливосберегающих масел SQ, соответствующее требованиям ILSAC.

## Что будет с маслами SP и GF-6

Масла API SP никуда не исчезают с полок и остаются качественными. Для ILSAC GF-6 предусмотрен переходный период, после которого маркировку «звёздочкой» смогут получать только масла GF-7. <!-- CHECK: дата окончания перехода для GF-6A — в источниках 31.03.2026 и 01.10.2026 -->

Категории API для бензиновых двигателей, как правило, обратно совместимы: масло нового уровня можно использовать там, где производитель требовал предыдущий. Но последнее слово — за руководством по эксплуатации и допуском автопроизводителя.

## Нужно ли срочно переходить на SQ

- **Если у вас новая машина** с рекомендацией API SQ/GF-7 — да, выбирайте масло этого уровня.
- **Если в руководстве указан API SP или GF-6** — масло SP по-прежнему подходит. Масло SQ тоже можно, если вязкость и допуск соответствуют требованиям.
- **Если в руководстве есть допуск автопроизводителя** (VW, BMW, MB, GM dexos и т. п.) — ориентируйтесь в первую очередь на него. Класс API — минимальный уровень, а допуск — конкретное требование к вашему двигателю.
- **Европейские автомобили** чаще требуют классы ACEA (C2, C3, A3/B4 и др.), а не API/ILSAC. Новая буква в API для них мало что меняет.

## Коротко

- API SQ / ILSAC GF-7 — новый стандарт для бензиновых двигателей, лицензируется с 31 марта 2025 года.
- Главные улучшения: защита от LSPI, износа цепи ГРМ, отложений в турбине, экономия топлива.
- GF-7A — для 0W-20…10W-30, GF-7B — только для 0W-16.
- Масла SP остаются в продаже и подходят там, где их требует производитель.
