Американский нефтяной институт (API) официально одобрил новое поколение стандартов для бензиновых моторных масел: ILSAC GF-7A, GF-7B и API SQ. С 31 марта 2025 года они действуют в системе лицензирования и сертификации моторных масел API (EOLCS), а ориентированы на автомобили 2026 модельного года и новее. Полки еще «переезжают» с SP на SQ — время разобраться, что меняется.

<!-- more -->

## Что нового в GF-7 и SQ

Задачи нового класса, по формулировке API, — топливная экономичность, улучшенная защита двигателя и снижение выбросов. Стандарты «рассчитаны на требования будущих технологий двигателей и грядущих регуляторных требований» (Билл О'Райан, старший менеджер EOLCS API).

Главное заметное изменение — введение ультранизковязких марок SAE 0W-8 и SAE 0W-12: это ответ на современные моторы, которые проектируются под минимальные гидравлические потери. Для сравнения: ещё недавно самым «жидким» массовым классом ILSAC был 0W-16 из GF-6B.

## Как читать маркировку: GF-7A и GF-7B

- **GF-7A** — основной класс; масла с ним получают сертификационный знак API «Starburst» (звёздочка), знакомый по канистрам последних лет.
- **GF-7B** — отдельная категория со знаком «Shield» (щит); она нужна, чтобы покупатель не залил масло не того класса в мотор, требующий конкретную спецификацию.

API SQ при этом охватывает критерии эффективности и для ресурсосберегающих масел (Resource Conserving), и для несберегающих — то есть класс описывает уровень качества шире, чем только экономию топлива.

## Классы сосуществуют, а не заменяют друг друга

API SP и GF-6 не «отозваны»: лицензии действуют, и масла прошлых классов продолжают выпускаться — парк из сотен миллионов автомобилей эксплуатируется именно на них. SQ/GF-7 — это про новые моторы: автопроизводители начнут указывать их в руководствах по мере выхода моделей 2026+ модельных лет. Для владельца старой машины правило прежнее: следовать руководству по эксплуатации, а не гнаться за самым свежим классом.

## Что это значит для вас

- Покупаете машину 2026 модельного года или новее — сверяйтесь с мануалом: там постепенно появится GF-7A или GF-7B, и заливать в такой мотор стоит именно их.
- Ездите на автомобиле прошлых лет — API SP/GF-6 остаётся корректным выбором; менять класс «на всякий случай» не нужно.
- Видите на канистре знак «Starburst» — это GF-7A, «Shield» — GF-7B; различие между ними существует не для маркетинга, а чтобы не перепутать классы.
- На российском рынке переход займёт время: пока встречаются и масла с двойной маркировкой «API SP / API SQ», и чисто SP-продукты — оба варианта легитимны для соответствующего парка.

## Коротко

С 31 марта 2025 года в системе лицензирования API действуют ILSAC GF-7A, GF-7B и API SQ — стандарты для машин 2026 модельного года и новее, с новыми ультранизковязкими марками 0W-8 и 0W-12. Старые классы остаются в силе для старого парка. Ориентир при выборе — руководство по эксплуатации, а не свежесть класса.
