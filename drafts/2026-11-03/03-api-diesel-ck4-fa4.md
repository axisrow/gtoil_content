На канистрах для коммерческого дизеля рядом с «классикой» 15W-40 всё чаще встречаются две аббревиатуры: API CK-4 и API FA-4. Буквы почти совпадают, но взаимозаменяемыми масла не являются: одна категория создана как преемник прежних классов, вторая — отдельная ветка под новые моторы, и её применение без прямого указания производителя техники недопустимо.

## Как устроены дизельные категории API

В системе API (American Petroleum Institute) дизельные моторные масла относятся к категории «C» (Commercial): первая буква обозначает ветку, вторая — поколение. Чем дальше буква по алфавиту, тем новее требования: каждое поколение ужесточает защиту от окисления, сажи, аэрации и коррозии подшипников, а также уменьшает износ.

С 1 декабря 2016 года API ввёл две категории одновременно — и это ключ к пониманию всей пары.

## CK-4: преемник с обратной совместимостью

CK-4 пришёл на смену CJ-4 и работает в моторах, рассчитанных на предыдущие классы — CJ-4, CI-4, CH-4 и старше. Это главное отличие: CK-4 обратно совместим, его можно лить там, где ранее применялся CJ-4.

Требования при этом выросли без смены философии: обычный диапазон HTHS (вязкость при высоких температурах и высокой скорости сдвига) — не ниже 3,5 мПа·с, привычные вязкости от 10W-30 до 15W-40, усиленная устойчивость к окислению и образованию отложений в турбине, совместимость с системами нейтрализации выхлопа (DPF, SCR), которые ужесточили требования к сульфатной зольности, фосфору и сере.

Для автопарка это означало простой переход: одна канистра CK-4 закрывает смешанный парк — и новые грузовики, и технику десятилетней давности.

## FA-4: экономия топлива с оговорками

FA-4 появился в тот же день, но построен на другой идее. Это низковязкие масла (типично 0W-30 и 10W-30) с пониженным HTHS — в диапазоне 2,9–3,2 мПа·с. Меньше внутреннее трение масла — ниже расход топлива, что для магистрального тягача, откатывающего сотни тысяч километров, превращается в ощутимую экономию.

Обратная сторона: плёнка тоньше, и защита рассчитана на моторы, спроектированные под эти зазоры и материалы. Поэтому FA-4:

- **не** обратно совместим со старыми категориями;
- **не** заменяет CK-4 в двигателях, для которых предписан обычный класс;
- применяется только там, где производитель техники прямо указал FA-4 (или собственный допуск, эквивалентный ему) в руководстве по эксплуатации.

Перепутать их на полке легко — этикетки похожи. Разница живёт в строке «HTHS» и в фразе «not backward compatible» на задней стороне упаковки.

## Как читать и выбирать

- Ищите на этикетке лицензионную марку API (кольцо с буквами класса): она означает, что масло лицензировано по программе API 1509 и прошло проверку состава.
- Категорию и вязкость берите из руководства по эксплуатации конкретной техники, а не «по традиции» из предыдущей машины.
- Для европейской техники класс API — часто недостаточно: нужны ACEA E-классы и допуски производителя (MB, Volvo, MAN и другие), которые ужесточают тесты сверх API.
- Не «улучшайте» класс вверх: FA-4 вместо CK-4 в несоответствующем моторе — риск износа подшипников на высоких нагрузках.

## Коротко

CK-4 — универсальный преемник CJ-4 с обратной совместимостью и обычным HTHS. FA-4 — низковязкая ветка с HTHS 2,9–3,2 мПа·с под экономию топлива, только для моторов, спроектированных под неё. Выбор определяет руководство по эксплуатации: на коммерческом транспорте ошибка в категории стоит дороже, чем разница в цене канистры.
