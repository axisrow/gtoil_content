На каждой канистре моторного масла — несколько непонятных кодов: SAE 5W-30, API SP, ACEA C3, а то и допуск вида MB 229.51. Это не маркетинг, а четыре системы, каждая из которых отвечает на свой вопрос. Разбираемся, что какая означает и в каком порядке читать.

<!-- more -->

## SAE: вязкость, а не качество

Класс SAE (например, 5W-30) описывает только текучесть: первое число с W — поведение на морозе, второе — вязкость при рабочей температуре. Это мы подробно разбирали в статье про 5W-30. Здесь важно одно: класс SAE ничего не говорит о ресурсе масла, моющих свойствах и защите от износа. За это отвечают следующие обозначения.

## API: базовая планка качества

Классификация американского института нефти (API) маркируется двумя буквами:

- **S** + вторая буква — для бензиновых двигателей (от «spark ignition»). По алфавиту требования ужесточаются: актуальный класс — **SP** (действует с 2020 года), предыдущие — SN Plus и SN;
- **C** + буква — для дизельных (от «compression ignition»), актуальный для тяжёлой техники — **CK-4**.

Масло для легковушки может иметь оба класса сразу (например, SN/CK-4) — это нормальная практика. Пиктограмма «Resource Conserving» рядом означает заявленную экономию топлива.

## ACEA: европейские требования, в том числе к зольности

Ассоциация европейских автопроизводителей (ACEA) делит масла иначе:

- **A/B** — легковые бензиновые и дизельные (например, A3/B4 — полновязкие масла с усиленной защитой);
- **C** — маловязкие масла с пониженным содержанием сульфатной золы, фосфора и серы (SAPS). Низкая зольность нужна машинам с сажевыми фильтрами (DPF) и нейтрализаторами: зола забивает фильтры. Самые ходовые классы — C2 и C3;
- **E** — коммерческий транспорт.

Важное следствие: машине с сажевым фильтром подходит только C-класс. Заливка полнозольного A3/B4 в такой мотор — прямой путь к дорогому ремонту фильтра.

## ILSAC: стандарт для азиатских и американских машин

ILSAC (объединение японских и американских автопроизводителей) актуализируется реже: действующая редакция — **GF-6** (с 2020 года). GF-6A соответствует API SP; GF-6B — то же самое для маловязких масел вроде 0W-16, которые заливают в современные гибриды и экономичные моторы. Если в руководстве японской машины указан ILSAC — ищите его на канистре наравне с API.

## Допуски автопроизводителей: главный код

API и ACEA — общие «планки». Допуск (например, VW 504.00, MB 229.51, BMW LL-04, GM dexos2) — это результат конкретных испытаний масла автопроизводителем под его моторы: свои требования к вязкости HTHS, зольности, топливной экономичности и совместимости с системами нейтрализации.

Порядок приоритетов при выборе простой:

1. Открыть руководство по эксплуатации: там указаны карта классов SAE и, для европейских машин, конкретные допуски.
2. Если допуск указан — искать его на канистре. Допуск важнее общего класса API/ACEA.
3. Проверить допуск можно в официальном списке одобрений на сайте автопроизводителя: у добросовестных марок номер стоит на канистре и в списках совпадает.

## Коротко

- SAE 5W-30 — вязкость (холодный пуск и рабочая температура), не качество.
- API SP / SN — базовая планка качества для бензина, CK-4 — для дизеля.
- ACEA C-классы — низкозольные масла для машин с сажевыми фильтрами; A3/B4 им не подходит.
- ILSAC GF-6 — параллельный стандарт для азиатских и американских авто.
- Есть допуск из руководства — ищите на канистре именно его: он главнее остальных кодов.
