На канистре рядом с привычными обозначениями API и ACEA часто стоит что-то вроде «VW 502 00» или «MB 229.5». Это допуски автопроизводителей — и для современных моторов они значат не меньше, а порой и больше, чем отраслевые классы.

<!-- more -->

## API и ACEA: общий минимум

API (American Petroleum Institute — Американский институт нефти) и ACEA (Европейская ассоциация автопроизводителей) — отраслевые классификации. Они описывают минимальный набор свойств масла для большой группы двигателей: вязкость при рабочих температурах, стойкость к окислению, защиту от износа, испаряемость.

Это как общий стандарт безопасности для всех машин сразу: полезно, но ни одна конкретная модель двигателя в испытании не участвует лично. Классификация усредняет требования по всему парку.

## Что такое допуск

Производитель автомобиля знает свой мотор лучше отраслевых институтов: какие материалы и покрытия использованы, какие зазоры в парах трения, как работает система изменения фаз, чем чреваты увеличенные интервалы замены. Поэтому концерны формулируют собственные требования и испытывают масла на своих двигателях.

Масло, прошедшее такую программу, получает допуск — официальное разрешение указывать код на канистре. Для покупателя это знак, что конкретная жидкость проверена именно на моторах этого производителя, а не «в среднем по парку».

## Разбираем пример: VW 502 00, 505 00 и 505 01

У концерна Volkswagen своя линейка кодов, и расшифровка хорошо показывает логику системы:

- **VW 502 00** — масла для бензиновых двигателей;
- **VW 505 00** — для дизельных двигателей без сажевого фильтра;
- **VW 505 01** — для дизелей с насос-форсунками (Pumpe-Düse): конструкция, где форсунка объединена с насосом высокого давления, и требования к маслу специфические.

Более современная пара — **VW 504 00** и **VW 507 00**: масла для увеличенных интервалов замены (LongLife), причём 507 00 — низкозольные, совместимые с сажевыми фильтрами.

Обратите внимание: 505 00 и 505 01 различаются не «уровнем качества», а применимостью к конкретной конструкции. Именно поэтому путать их нельзя.

## Не только Volkswagen

У каждого крупного концерна свои линейки. Mercedes-Benz 229.5 — масла для бензиновых и дизельных моторов с увеличенными интервалами замены, BMW Longlife-04 — низкозольные масла для автомобилей с сажевыми фильтрами. У азиатских производителей поверх API и ILSAC часто действуют собственные требования.

## Как пользоваться на практике

1. Откройте руководство по эксплуатации: там указаны и класс по API/ACEA, и необходимые допуски.
2. На канистре ищите прямое указание допуска — надпись или номер в списке соответствий.
3. Если в руководстве указан допуск, он приоритетнее общего отраслевого класса.
4. Надпись «подходит для…» — не допуск: соответствие лучше проверять по официальным спискам масел на сайтах автопроизводителей.

## Коротко

- API и ACEA — минимальный отраслевой стандарт для миллионов моторов сразу.
- Допуск — подтверждение испытаний на конкретных двигателях конкретного концерна.
- Правильный порядок выбора: руководство → допуск → класс API/ACEA, а не наоборот.
