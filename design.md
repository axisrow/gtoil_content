# Формат канала @gtoil_club

Дизайн постов Telegram-канала. Здесь же — исследование конкурентов, на котором формат основан.
Механика постинга — `scripts/social.py send` (Bot API) + `.github/workflows/tg-publish.yml`.

## Исследование (2026-10-27, публичные данные)

| Канал | Тип | Постов/день | Формат |
|---|---|---|---|
| ZIC, Liqui Moly, G-Energy/Газпромнефть-СМ, ЛУКОЙЛ | бренды-конкуренты | **каналов не найдено** | — |
| «За рулём» (@zr_ru, 73K) | авто-СМИ | 10–15, интервал 1–3 ч | эмодзи + жирный заголовок, 1–4 абзаца (~150 слов), фото почти в каждом посте, минимум хэштегов, опросы/реакции |
| CAR ONLINE (@caronline) | новостной агрегатор | 10–17, пачками к вечеру | ультракороткие 1–6 строк, без внешних ссылок, реакции как эмодзи |
| Профильные масляные каналы | дистрибьюторы | приватные чаты | не видны публично |

Выводы:

1. **Ниша свободна.** Заметных брендовых TG-каналов производителей масел нет — @gtoil_club будет пионером сегмента. Ориентироваться на авто-СМИ, а не на бренды.
2. **Частота.** 5 постов/день — скромно по меркам TG (СМИ дают 10–15) и достаточно для нашей воронки «статья → сайт». Разнос в течение дня обязателен: пачки убивают охват.
3. **Длина.** Пост самодостаточный: полный текст статьи прямо в сообщении (лимит Telegram — 4096 знаков; длиннее — укороченная версия с «…» на конце). Лонгрид «по клику» отвергнут 2026-10-28: ссылки в TG кликают редко, текст должен работать сам.
4. **Медиа.** У «За рулём» фото почти в каждом посте — самый заметный элемент формата. У нас обложек нет, пост — чистый текст. Когда появятся обложки — включить `sendPhoto` (см. «Потом», ниже).

## Формат поста

Стиль канала (2026-10-28): **полный текст статьи в посте** — заголовок, лид, разделы, «Коротко».

Правила:

- **Текст** — содержимое одобренной статьи дословно: `<!-- CHECK -->`-комментарии и отсечка `<!-- more -->` вырезаются, заголовки разделов — обычными строками. Лимит Telegram 4096 знаков; длиннее — укороченная версия с «…» (укорачивается тело, не заголовок).
- **Разметка не рендерится**: посты идут plain text (tg-agent и Bot API без parse_mode) — без `**болда**`, эмодзи и декоративных маркеров.
- **Ссылки**: ссылки на GitHub Pages — служебные, в посты запрещены (правило 2026-10-27). Вернуть `{url}` сайта — только после появления боевого домена.
- **Тон** — как в статьях: спокойный эксперт.
- **Хэштеги** — по решению на пост; в текущем стиле канала их нет.
- **Время**: 09:00, 12:00, 15:00, 18:00, 21:00 МСК (cron `0 6,9,12,15,18 * * *` UTC), по посту на слот.

## Механика

- `scripts/social.py send`: рендер статьи (полный текст) → пост в @gtoil_club (Bot API) либо из аккаунта владельца через tg-agent (`dialogs send`).
- Журнал — `content/social.json`: slug → сеть → ссылка/время. Повторы исключены: `send` берёт первую статью последних дней без записи `telegram`.
- Токен бота — секрет `TELEGRAM_BOT_TOKEN` (для CI-режима), бот — админ @gtoil_club с правом публикации; ручной режим — из аккаунта владельца через tg-agent.

## Потом (не сейчас)

- Обложки статей → `sendPhoto` с caption вместо `sendMessage` (когда появится генерация картинок).
- Реакции/опросы после поста — руками, не автоматом.
- Расширение на другие сети из `config/social.yaml` — механика та же, добавится сеть в конфиг.
