# Стиль

## Контекст
- Контент для бренда GT OIL (Hanval Inc., Южная Корея, https://gtoil.ru/). Конкуренты — `config/competitors.yaml`: их не упоминаем и не сравниваем с ними.

## Аудитория и голос
- Автовладельцы, механики СТО, закупщики автопарков и промышленных предприятий. Читатель неглупый, но не химик.
- Тон: спокойный эксперт-практик. Без канцелярита, без рекламных восторгов, без «в современном мире».
- Русский язык. Термины в первом упоминании поясняй: «вязкостный класс SAE 5W-30 — …».
- Не продвигай конкретные бренды. Бренды упоминай только в новостях как факт.

## Структура
- Заголовок: конкретный, с пользой или фактом. Без кликбейта и вопросов «А вы знали?».
- Лид (1–2 предложения): суть и зачем читать.
- 3–6 подзаголовков `##`, короткие абзацы, списки где уместно.
- Практический вывод в конце: «Что это значит для вас» / «Коротко».
- Для новостей: что произошло → кто/когда/цифры → почему важно → источник.

## Факты — жёстко
- Ничего не выдумывать: номера допусков (VW 504.00, MB 229.51, BMW LL-04…), классы API/ACEA/ILSAC, цифры вязкости, щелочное число, даты вступления спецификаций, цены, цитаты.
- Если не уверен — либо проверь WebSearch, либо сформулируй общо, либо поставь в тексте `<!-- CHECK: что проверить -->`.
- Каждое утверждение из новости — с источником в `sources`. В тексте можно ссылаться: «по данным Lubes'n'Greases».
- Советы по безопасности и гарантии: всегда «сверяйтесь с руководством по эксплуатации / допуском производителя».
- Не путать: вязкость ≠ качество; синтетика ≠ «всегда лучше»; API ≠ ACEA.

## Запрещено
- Медицинские/экологические страшилки без источника.
- Утверждения о конкретных продуктах «лучшее/худшее».
- Копировать текст источника больше одной цитаты-предложения.
